# Serviços de Manutenção Residencial
SENAI - Projeto de Serviços de Manutenção Residencial

Definição da stack tecnológica (Linguagem, Framework, Banco de Dados Relacional/NoSQL):

Para o desenvolvimento do sistema de Serviços de Manutenção Residencial, foi definida uma stack tecnológica composta por JavaScript como linguagem de programação,
Node.js como ambiente de execução, Express.js como framework e MySQL como banco de dados relacional.
